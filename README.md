# 假名手帖

一個適合手機使用的日文手寫練習 PWA。收錄基本 46 個平假名、46 個片假名，以及食物、動物、日常三類共 30 個單詞。進度只保存在使用者的裝置上。

## 線上使用

手機開啟：<https://u10617020.github.io/hiragana-notebook/>

開啟後可從瀏覽器選單加入主畫面，像一般 App 一樣使用。

## 在本機開啟

PWA 的離線功能需要透過 `http://` 或 `https://` 開啟，不能直接雙擊 HTML 檔案。若電腦有 Python，可在此資料夾執行：

```text
py -m http.server 4173
```

再用瀏覽器開啟 `http://localhost:4173/`。

## 部署

將整個資料夾原樣放到任何支援 HTTPS 的靜態網站服務即可，不需要建置步驟。`index.html`、`app.js`、`styles.css`、`manifest.webmanifest`、`service-worker.js` 和 `icons/` 必須維持相對位置。

## 使用方式

1. 從首頁選平假名、片假名或單詞練習。單詞再按食物、動物、日常分類。
2. 假名是前三格描字、後五格默寫；單詞是前兩格描寫、後三格默寫。
3. 每格至少寫一筆後，按「完成練習」。完成的每格算一次書寫；寫錯可先清除或復原。
4. 依自己的掌握程度標記「我會了」或「再練一下」，也可隨機複習。
5. 首頁顯示總書寫次數、今日完成頁數（每日目標五頁）與連續練習天數。
6. iPhone 可從 Safari 的分享選單加入主畫面；Android 可從 Chrome 選單安裝。

## 隱私

不需帳號，也不會傳送或保存手寫筆跡。學習狀態、書寫次數、完成次數、每日練習與最後練習時間只存放在瀏覽器的 `localStorage`。舊版平假名的狀態與完成次數會自動帶入新版。書寫次數代表完成的格數，不是字形正確率。
